# Guía de colores — PROPRINT

## Identidad visual
PROPRINT utiliza una interfaz de producción clara, profesional y legible, con fondos azulados suaves, acentos índigo y estados semánticos.

| Uso | Color | Hex |
|---|---|---|
| Fondo claro | Azul niebla | `#F4F7FB` |
| Texto principal | Azul pizarra | `#243044` |
| Texto secundario | Gris azulado | `#95A2B7` |
| Marca y acciones | Índigo PROPRINT | `#6D81DF` |
| Verde operativo | Menta | `#60C79D` |
| Programado | Lavanda | `#8294E1` |
| En riesgo | Ámbar | `#E5AF5B` |
| Retrasado | Rosa coral | `#DC8590` |

## Tema oscuro
- Fondo: `#111827` / `#182235`
- Superficie: `rgba(30, 41, 59, 0.70)`
- Texto principal: `#E7EDF8`
- Texto secundario: `#9EACC4`
- Acento: `#B8C5FF`

## Gantt
Las órdenes usan lavanda `#E9E7FB`, menta `#DDF4EB`, durazno `#FBE8DC` y azul `#E2EBFB`. Cada orden muestra hora de entrada, hora de salida y duración en una fila propia para evitar confusiones.

## Tipografía
Arial, Helvetica, sans-serif. Los identificadores de pedidos y SKU usan tipografía monoespaciada.
